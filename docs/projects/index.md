## 单个成果页的写法建议

新建 `docs/projects/项目名.md`，按这四块写：

### 1. 做了什么

一句话说清目标，例如"在 0.96 寸 OLED 上显示中文，字库存在内部 Flash"。

### 2. 用了什么

- 硬件：STM32F103C8T6 / SSD1306 / …
- 关键知识点：字模取模、页地址模式、显存位映射

### 3. 关键代码或截图

```c
/* 关键片段，不要贴整份工程 */
OLED_ShowChinese(0, 0, 0);
```

### 4. 遇到的问题与解决

问题 → 排查过程 → 原因 → 最终方案。**这一段半年后最值钱。**
