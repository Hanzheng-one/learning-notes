# STM32 GPIO 八种输出模式

> 这是**样例笔记**，展示推荐的结构。照着改就能用，不需要保留本页。

## 一句话结论

GPIO 的八种模式由 `CRL` / `CRH` 两个寄存器里每 4 位一组的 `MODE[1:0]` + `CNF[1:0]` 决定。

## 原理

每个引脚在配置寄存器里占 **4 个 bit**：

| 位 | 名称 | 作用 |
|---|---|---|
| `MODE1:0` | 输出速度 / 输入保留 | `00` 输入，`01` 10MHz，`10` 2MHz，`11` 50MHz |
| `CNF1:0` | 配置位 | 配合 MODE 决定具体模式 |

八种模式速查：

| CNF | MODE=00（输入） | MODE≠00（输出） |
|---|---|---|
| `00` | 模拟输入 | 通用推挽输出 |
| `01` | 浮空输入 | 通用开漏输出 |
| `10` | 上拉/下拉输入 | 复用推挽输出 |
| `11` | 保留 | 复用开漏输出 |

## 代码片段

```c
/* 把 PA0 配成 50MHz 推挽输出：CNF=00, MODE=11 → 0x3 */
GPIOA->CRL &= ~(0xF << 0);   /* 先清空低 4 位 */
GPIOA->CRL |=  (0x3 << 0);   /* 再写入 0011 */
```

## 踩坑记录

!!! warning "LED 不亮的第一嫌疑"
    推挽输出没问题，但**忘了使能时钟**：

    ```c
    RCC->APB2ENR |= 0x04;   /* 使能 GPIOA 时钟 */
    ```

    没有时钟，寄存器写了也不生效——外设根本没通电。
