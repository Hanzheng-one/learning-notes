# 复习与复盘

笔记是"存进去"，这一页是"取出来"。没有回顾的学习站，等于一个没人看的仓库。

## 三种回顾方式

### 1. 搜索式回顾（最省力）

右上角搜索框直接搜关键词。适合"我明明记过但忘了叫什么"的场景。

### 2. 状态式回顾（建待办）

笔记头部的 front matter 里写 `status: 待复习`，
需要清理欠账时搜 `status: 待复习`，一次拉出全部。

推荐的状态取值：

| 状态 | 含义 |
|---|---|
| `学习中` | 刚接触，还没跑通 |
| `待复习` | 当时懂了，但需要再巩固 |
| `已掌握` | 能独立复现，不用再看 |

### 3. 周期式回顾（最有效）

每周固定一天写一篇复盘，放在本目录下，命名 `YYYY-Www-周复盘.md`。
模板见 [_template-周复盘.md](_template-周复盘.md)。

## 错题 / 易错点

把反复踩的坑单独攒一页，比散落在各篇笔记里更容易记住。

- 外设写了寄存器不生效 → **先查时钟有没有使能**（RCC->APBxENR）
- 位操作 `|=` 之前忘了 `&= ~` 清位，导致旧配置残留
